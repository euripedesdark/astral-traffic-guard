**Proxy Inverso de Alto Rendimiento, Motor de ACL y Filtrado Web en Rust** — Módulo corporativo del ecosistema Astral para control de navegación, balanceo de carga L7 y aplicación de políticas de acceso, desarrollado con arquitectura orientada a objetos en Rust.

Consulte [`LICENSE.md`](LICENSE.md) para la licencia **GNU AGPL v3**.

---

## 🎯 Características Principales

- **Arquitectura Orientada a Objetos en Rust**: Separación desacoplada en capas (`domain/`, `service/`, `controller/`) con polimorfismo mediante traits dinámicos.
- **Motor de ACL Ultrarrápido**: Evaluación de reglas en menos de 2ms con caché en memoria.
- **Endpoint `auth_request`**: Integración con proxies de borde (`/api/v1/acl/check`).
- **Consola de Administración**: SPA en React 18, Vite y TypeScript con soporte multilingüe en 4 idiomas.
